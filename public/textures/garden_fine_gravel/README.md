# Fine garden gravel

Unmodified PBR maps from [Gravel Floor 03](https://polyhaven.com/a/gravel_floor_03),
by Charlotte Baglioni, Poly Haven, [CC0](https://polyhaven.com/license).
Downloaded 2026-09-27 through the Poly Haven files API; every JPEG was checked
against the source MD5. Diffuse is 2K, OpenGL normal and roughness are 1K.
The scan represents **2.5 x 2.5 metres**. Used only for the kitchen-garden and
fire-lounge gravel walks; the general river-pebble catalogue material is unchanged.

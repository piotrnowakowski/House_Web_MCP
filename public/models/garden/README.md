# Garden model assets

The four fruit-tree base meshes are selected variants from Quaternius' Stylized Nature MegaKit:

- Source: https://quaternius.com/packs/stylizednaturemegakit.html
- Download mirror/catalogue: https://poly.pizza/bundle/Stylized-Nature-MegaKit-T34GZFA0fm
- Author: Quaternius
- License: CC0 1.0 Universal

The source glTF files were converted to local binary GLB assets by Poly Pizza. For this application they were losslessly reorganized with Meshopt geometry compression and their embedded 1024 px PNG textures were resized to 512 px WebP using glTF Transform. The files remain local runtime assets; the application does not hotlink the source library.

Species identity is supplied by the application's semantic plant records and lightweight seasonal fruit/blossom geometry. The imported meshes provide distinct deciduous tree silhouettes rather than claiming botanical scan accuracy.
